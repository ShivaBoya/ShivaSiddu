# THE INDUVERSE — An Extraordinary Birthday Experience ✨

> A bespoke, cinematic, luxury interactive romantic web experience created exclusively for **Indu** by **Shiva** (December 01, 2026).

---

## 🌟 Overview

**The Induverse** is an interactive, cinematic journey combining luxury digital art direction, 3D WebGL graphics, motion design, and personal romantic memories into seven full-screen chapters:

1. **Scene 01 — First Encounter:** A full-bleed realistic blooming crimson rose with interactive 3D parallax, floating glowing romantic hearts, drifting petals, and an interactive particle burst.
2. **Scene 02 — The Induverse (3D Galaxy):** An interactive Three.js starry cosmic universe featuring nebula dust clouds and four interactive constellation beacons (*Indu Alpha*, *Stella Serena*, *Lyra Aurea*, *Vega Amoris*).
3. **Scene 03 — The Beauty of Indu:** A luxury editorial exhibition showcasing high-resolution portraits of Indu with gold-framed viewing, zoom lightbox, and custom typography.
4. **Scene 04 — Scrapbook of Memories:** A nostalgic desk setting with polaroid photographs, handwritten notes, and horizontal swipe navigation.
5. **Scene 05 — The Enchanted Garden:** A moonlit fairytale sanctuary featuring bioluminescent fireflies, drifting petals, fluttering butterflies, and five unique living blossoms with sacred secret truths.
6. **Scene 06 — The Birthday Celebration:** A central gourmet royal celestial blue birthday cake with physically mapped interactive candlelight, tap-to-extinguish smoke physics, and an explosion of celebration confetti.
7. **Scene 07 — A Letter Across the Stars:** The grand climax revealing the couple photograph of Shiva and Indu, along with a romantic birthday letter and falling petals.

---

## 🚀 Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS with custom luxury color palette (Champagne Gold, Midnight Navy, Burgundy Wine, Emerald Sanctum)
- **3D Graphics:** Three.js + React Three Fiber + Drei
- **Motion & Transitions:** Framer Motion with custom physics curves
- **Audio:** Web Audio API with ambient soundtrack and interactive sound effects
- **Responsive Architecture:** Mobile-First design supporting `100dvh`, iOS safe areas, and touch gestures (tap, swipe, tilt)
